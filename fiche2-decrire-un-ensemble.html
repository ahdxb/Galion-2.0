Décrire un ensemble

Vocabulaire et notations

Domaine de référence. Quand on écrit $\{\,x \in E \mid P(x)\,\}$ où $P(x)$ est une propriété portant sur $x$, le « $\in E$ » précise le domaine dans lequel on cherche. Sans domaine clair, l'ensemble peut être mal compris.

  • Soit $A = \{n \in \mathbb{N} \mid n < 4\}$. Le domaine est $\mathbb{N} = \{0, 1, 2, 3, \ldots\}$ et $A = \{0, 1, 2, 3\}$.
  • Soit $B = \{n \in \mathbb{Z} \mid n < 4\}$. Le domaine est $\mathbb{Z} = \{\ldots, -2, -1, 0, 1, 2, \ldots\}$ et $B = \{\ldots, -2, -1, 0, 1, 2, 3\}$ est beaucoup plus grand que $A$ !

Combiner des conditions. La propriété peut comporter plusieurs critères :

  • $\{x \in E \mid P(x) \text{ et } Q(x)\}$ : $x$ vérifie les deux propriétés $P$ et $Q$ (par exemple, $x$ est pair et $x > 10$).
  • $\{x \in E \mid P(x) \text{ ou } Q(x)\}$ : $x$ vérifie au moins une des deux propriétés $P$ et $Q$ (attention : en maths, le « ou » est inclusif : « A ou B » est vrai lorsque A est vrai et B est vrai).

Bien défini. Pour qu'une description désigne vraiment un ensemble, le critère doit être sans ambiguïté : on doit pouvoir dire, pour chaque élément, si oui ou non il vérifie la propriété.

  • ✓ « $n$ est divisible par 3 » : un entier l'est ou ne l'est pas, sans débat.
  • ✗ « $x$ est grand » : « grand » dépend du juge.

Égalité par équivalence. Deux descriptions désignent le même ensemble si leurs propriétés sont vraies pour exactement les mêmes éléments. Pour montrer $\{x \in E \mid P(x)\} = \{x \in E \mid Q(x)\}$, on prouve que pour tout $x \in E$, $P(x)$ équivaut à $Q(x)$.

Exemples

  • « $2 \leqslant n \leqslant 5$ » est un raccourci (une facilité d'écriture) pour « $2 \leqslant n \text{ et } n \leqslant 5$ ».
  • $\{m \in \mathbb{N} \mid m \text{ pair}\} = \{0, 2, 4, 6, \ldots\}$ est un exemple d'ensemble infini.
  • $\{a \in \mathbb{N} \mid a \text{ pair et } a \leqslant 6\} = \{0, 2, 4, 6\}$.
  • $\{b \in \mathbb{Z} \mid b^2 \leqslant 4\} = \{-2, -1, 0, 1, 2\}$.
  • $\{n \in \mathbb{N} \mid n \text{ pair et } n \text{ multiple de 3}\} = \{n \in \mathbb{N} \mid n \text{ multiple de 6}\}$ sont deux descriptions équivalentes du même ensemble.
  • Soit $P(k)$ la propriété « $k^2 \leqslant 10$ » et $Q(m) : -3 \leqslant m \leqslant 3$. Alors $\{k \in \mathbb{Z} \mid P(k)\} = \{-3, -2, -1, 0, 1, 2, 3\} = \{m \in \mathbb{Z} \mid Q(m)\}$. Note que le choix des lettres $k$ et $m$ n'a pas d'importance : ce sont des variables muettes.

Pour s'entraîner

  1. Donne en extension : $\{n \in \mathbb{N} \mid n \text{ pair et } n < 12\}$.
  2. Cet ensemble est-il bien défini ? $\{x \in \mathbb{N} \mid x \text{ est un grand nombre}\}$. Justifie.
  3. Vrai ou faux ?  $\{n \in \mathbb{N} \mid n \neq 0\} = \{n \in \mathbb{N} \mid n \geqslant 1\}$.
Pour aller plus loin.  Que vaut $\{n \in \mathbb{N} \mid n^2 < 0\}$ ? Et $\{x \in \mathbb{R} \mid x^2 + 1 = 0\}$ ? → voir l'exercice 8 (page suivante).
FICHE 2 · EXERCICES Décrire un ensemble

★Application directe

  1. Donne en extension :
    1. $\{n \in \mathbb{N} \mid n \leqslant 4\}$
    2. $\{n \in \mathbb{N} \mid n \text{ pair et } 0 < n < 10\}$
    3. $\{n \in \mathbb{Z} \mid -2 \leqslant n \leqslant 2\}$
    4. $\{n \in \mathbb{N} \mid n = 1 \text{ ou } n = 4 \text{ ou } n = 9\}$
  2. Les ensembles ci-dessous sont-ils bien définis ou non ? Justifie en une phrase.
    1. $\{x \in \mathbb{N} \mid x \text{ est multiple de 7}\}$
    2. $\{x \in \mathbb{N} \mid x \text{ est petit}\}$
    3. $\{x \in \mathbb{N} \mid x \text{ est intéressant}\}$
    4. $\{x \in \text{humains} \mid x \text{ est né en l'an 2000}\}$
    5. $\{x \in \mathbb{R} \mid x = \pi\}$
    6. $\{x \in \text{humains} \mid x \text{ mesure plus de 1{,}70 m}\}$

★★Comprendre et traduire

  1. Décris en compréhension restreinte (avec un domaine $E$ explicite) :
    1. Les multiples de 5 strictement positifs et inférieurs à 50.
    2. Les nombres impairs entre 10 et 30.
    3. Les solutions de $x^2 = 9$ dans $\mathbb{Z}$.
    4. Les nombres premiers strictement plus petits que 20.
  2. Le domaine compte. Pour chaque cas, donne en extension les deux ensembles et conclus s'ils sont égaux.
    1. $A = \{x \in \mathbb{N} \mid x^2 = 4\}$ et $B = \{x \in \mathbb{Z} \mid x^2 = 4\}$.
    2. $A = \{x \in \mathbb{N} \mid 0 \leqslant x < 3\}$ et $B = \{x \in \mathbb{Z} \mid 0 \leqslant x < 3\}$.
  3. Reformuler la propriété sans changer l'ensemble. Pour chaque ensemble, donne deux écritures différentes en compréhension (deux propriétés équivalentes) :
    1. $\{0, 2, 4, 6, 8\}$ dans $\mathbb{N}$.
    2. $\{1, 4, 9, 16, 25\}$ dans $\mathbb{N}$.
  4. Le mot « ou ».
    1. Donne en extension : $\{n \in \mathbb{N} \mid n = 0 \text{ ou } n \text{ pair}\}$.
    2. Un même $n$ peut-il satisfaire les deux conditions à la fois (être 0 ET être pair) ? Si oui, lequel ?
    3. En français courant, « fromage ou dessert » est exclusif. Conclus sur le sens du « ou » en math.

★★★Pousser plus loin

  1. Égalité par équivalence. Montre que $\{n \in \mathbb{N} \mid n \text{ pair et } n \text{ multiple de 3}\} = \{n \in \mathbb{N} \mid n \text{ multiple de 6}\}$.
    Indice : prends un $n$ du membre de gauche et montre qu'il est dans celui de droite, puis l'inverse.
  2. Trois écritures de l'ensemble vide. Donne trois descriptions différentes de $\emptyset$ en compréhension restreinte (chacune avec un domaine bien choisi).
  3. Bien défini ou pas ? Pour chaque description, dis si elle est bien définie ; si oui, donne en extension (ou explique pourquoi infinie) ; si non, identifie l'ambiguïté.
    1. $\{n \in \mathbb{N} \mid n \text{ se termine par 7 dans son écriture décimale}\}$
    2. $\{x \in \mathbb{R} \mid x \text{ est proche de 0}\}$
    3. $\{n \in \mathbb{N} \mid n \text{ est solitaire}\}$
    4. $\{x \in \mathbb{R} \mid x \text{ est rationnel}\}$
